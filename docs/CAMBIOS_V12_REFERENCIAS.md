# GeoCost SC V12 — referencias tarifarias restauradas

- Se mantienen las listas independientes de costos variables y fijos (MXN y porcentaje del costo técnico), margen y tarifa base.
- Se restauran referencias de escenarios C, C´, B, B+ y B SPOT en la pantalla principal y en el reporte ejecutivo. **No son tablas oficiales CEMEX.**
- C = tarifa base (costo técnico + utilidad). Las demás referencias son recargos configurables sobre C (valores iniciales: +4 %, +9 %, +14 % y +20 %), editables en Configurar costos, sección 7.
- El cálculo de diésel y peajes sin IVA, la detección automática parcial de casetas, los lotes óptimos y la operación sin API key se conservan de V11.
- Los escenarios tarifarios adicionales no cambian el costo técnico ni los rubros: son niveles comparativos sobre la base C.
